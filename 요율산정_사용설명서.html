이 도구는 무엇인가

경비·미화·시설관리처럼 사람을 파견받는 외주 용역의 월 청구금액을 법정 기준대로 계산하는 도구입니다. 업무별로 근무형태·시급·인원을 넣으면 법정수당, 4대보험, 퇴직충당금, 복리후생비, 관리비까지 붙여 1인 청구단가와 월·연간 총액을 산출하고, 업체가 낸 견적과 나란히 비교해 줍니다.

이 순서가 화면의 상세 내역, 엑셀 「산정내역」 시트의 행 순서와 모두 같습니다. 이 그림 하나만 기억하면 어느 화면이든 읽을 수 있습니다.

5분 빠른 시작

처음 열면 경비 3명 · 격일제 예시 업무가 하나 들어 있습니다. 이걸 고쳐 가며 익히는 것이 가장 빠릅니다.

  1. 업무 추가 — 왼쪽 「👷 업무 목록」의 + 업무 추가를 누르거나 예시 카드를 고칩니다. 업무명과 교대형태를 고르면 월 근무시간이 자동으로 채워집니다.
  2. 시급·인원·산재율 입력 — 단가표가 있으면 「직종」 칸에서 직종을 검색해 고르면 시급이 자동으로 들어갑니다.
  3. 공통 비용 확인 — 복리후생비(식대 등)와 기타 고정비, 관리비율을 계약 조건에 맞게 조정합니다. 4대보험 요율은 2026년 기준이 이미 들어 있습니다.
  4. 결과 확인 — 가운데 요약 카드와 「업무별 청구 요약」에서 1인 청구단가와 월·연간 총액을 봅니다.
  5. 저장하고 내보내기 — 📂 저장/불러오기로 저장하고, 📥 엑셀 다운로드로 결재용 파일을 받습니다.
숫자 입력 팁 업무 카드의 숫자 칸(시급·인원·근무시간 등)은 Enter를 누르거나 다른 칸을 클릭해야 계산에 반영됩니다. 타이핑 도중에 합계가 바뀌지 않는 것은 정상입니다.

근무시간 칸 읽는 법 — 꼭 알아둘 것

「기본급 대상」은 연장·야간·휴일을 모두 포함한 유급 전체 시간입니다. 그 아래 칸들은 그 시간 중 가산이 붙는 구간이고, 가산분(0.5배)만 추가로 더합니다. 트리(├└)와 배수 칩(×1.0 / +0.5)이 이 포함관계를 보여줍니다.

칸계산입력 요령

경고 표시 시급이 최저시급(10,320원)보다 낮으면 빨간 배너, 연장이 월 52h(주 12h 한도)를 넘으면 노란 배너가 뜹니다. 금액 계산에는 영향이 없는 알림입니다. 격일제 경비처럼 고용노동부 감시·단속적 근로 승인을 받은 업무는 근로시간 적용제외(§63)를 체크하면 연장 경고가 사라집니다.

2직종 단가표

시중노임단가 같은 「직종 → 일급」 표를 불러와, 업무 카드에서 직종을 고르면 시급을 자동으로 채우는 기능입니다. 일급 ÷ 8시간 = 시급으로 환산합니다(예: 172,068원 ÷ 8 = 21,509원).

표는 어디서 오나

  • 기본 표 — 도구를 사내 웹 주소(GitHub Pages 등)로 열면 함께 둔 단가표.xlsx를 자동으로 읽습니다.
  • 직접 올린 표 — 파일을 PC에서 바로 열었거나 다른 표를 쓰려면 「💰 직종 단가표」 패널의 📥 다른 표 올리기로 엑셀을 올립니다. 올린 표가 기본 표보다 우선하며, 브라우저에 기억됩니다.
  • 표가 없으면 직종 칸이 숨겨지고 시급을 직접 입력하면 됩니다.

열 순서나 제목 위치는 자유롭습니다. 앞쪽 10행 안에서 아래 제목을 알아서 찾습니다.

단위선택단위 — 일 / 시간 / 월. 없으면 「일」로 간주 (월 단가는 ÷209h)

단가가 0·공란·「-」인 행은 자동으로 제외되고, 같은 이름의 직종은 분야·적용월을 괄호로 붙여 구분합니다.

업무 카드에서 쓰기

  1. 직종 칸에 검색어 입력 — 직종명뿐 아니라 해설 내용으로도 찾습니다(예: 「지게차」).
  2. 목록에서 고르면(↑↓ + Enter 가능) 시급이 채워지고, 표에 산재율이 있으면 산재율도 채워집니다.
  3. 시급은 계속 고칠 수 있습니다. 고치면 카드 아래 근거 줄이 「✏️ 직접 수정」으로 바뀌고 단가로 되돌리기 링크가 생깁니다.
반기 단가 갱신 새 단가표를 올리면 "직종이 지정된 업무의 시급도 갱신할까요?"라고 묻습니다. 확인 한 번으로 모든 업무의 시급이 새 단가로 바뀝니다.

단가표는 참조 자료라 초기화로 지워지지 않습니다. 올린 표를 버리려면 패널의 기본 표로 복귀를 누르세요.

3기준시급 × 적용률

"노임단가의 85%를 시급으로 한다" 같은 계약 조건을 그대로 기록하는 기능입니다. 금액만 넣으면 나중에 근거를 알 수 없지만, 이 기능을 쓰면 화면·엑셀·복사 결과에 「기준 21,509원 × 85% = 18,283원」처럼 남습니다.

  1. 업무 카드의 시급 라벨 옆 기준×%를 누릅니다.
  2. 「기준시급 × 적용률」 줄이 나타납니다. 켜는 순간에는 기준 = 현재 시급, 율 = 100%라 금액이 바뀌지 않습니다.
  3. 기준시급이나 적용률을 고치면 시급이 자동으로 다시 계산됩니다.
  4. 끄려면 그 줄의 끄기. 이때도 금액은 그대로입니다.
단가표와 함께 쓰면 직종 선택·단가표 교체·인상률 반영이 모두 기준시급 쪽을 바꾸고, 협상으로 정한 적용률(%)은 유지됩니다. 즉 단가표만 갱신하면 "새 단가의 85%"가 자동으로 맞춰집니다.

4근무표 직접 만들기

표준 교대형태에 맞지 않는 근무(예: 주 4일 12시간, 주말 포함 순환)를 달력에 직접 그려서 월평균 근무시간으로 자동 환산하는 기능입니다. 업무 카드의 🗓 근무표 직접 만들기 또는 교대형태 「커스텀(달력)」을 고르면 열립니다.

  • 항목별 차이표 · 그래프(하단) — 상세 입력한 업무만 모아 항목별로 전체 인원 기준 월 차이를 보여줍니다.

자주 묻는 질문 · 주의사항

숫자를 고쳤는데 합계가 안 바뀌어요

업무 카드의 숫자 칸은 Enter 또는 다른 칸 클릭으로 확정해야 반영됩니다. 엑셀 다운로드·결과 복사·저장은 입력 중인 값도 자동으로 확정한 뒤 실행됩니다.

연장·야간 시간을 기본급 대상에서 빼야 하나요?

아니요. 기본급 대상은 전체 유급시간이고 연장·야간·휴일 칸은 그중 가산분만 더합니다. 빼면 기본급이 과소 계산됩니다.

직종 칸이 안 보여요

단가표가 없는 상태입니다. 파일을 PC에서 바로 열면 기본 표를 자동으로 읽지 못하니, 「💰 직종 단가표」에서 엑셀을 올리세요.
